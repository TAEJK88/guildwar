🌐 โหมดออนไลน์ — ทุกคนที่เปิดลิงก์ห้องเดียวกันจะเห็นตี้อัปเดตแบบเรียลไทม์ กด "🔗 ก๊อปลิงก์ห้อง" แล้วส่งให้สมาชิกกิลได้เลย
⚠️ ยังไม่ได้ตั้งค่า Firebase — ตอนนี้ใช้งานแบบออฟไลน์ได้ปกติ (บันทึก/เปิดไฟล์) ถ้าอยากให้ข้อมูลแชร์กันสด ทำตามนี้:
1) เข้า console.firebase.google.com → สร้างโปรเจกต์ใหม่ (ฟรี)
2) เมนู Build → Realtime Database → Create Database (เลือก asia-southeast1) → เริ่มแบบ Test mode
3) หน้า Project Overview กดไอคอน </> (Add web app) → ก๊อปค่า firebaseConfig
4) เปิดไฟล์นี้ด้วย Notepad แล้ววางค่าแทนที่บล็อก firebaseConfig ที่ทำเครื่องหมายไว้ (หรือส่งค่ามาให้ผมใส่ให้ก็ได้)
5) อัปโหลดไฟล์ขึ้น GitHub Pages / Netlify แล้วแชร์ลิงก์ให้กิล
